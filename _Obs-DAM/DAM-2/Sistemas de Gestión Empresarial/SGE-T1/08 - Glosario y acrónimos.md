# 8 · Glosario y acrónimos

↩️ [[SGE-T1]]

## Glosario

| Término | Definición |
|---|---|
| **Acrónimo** | Siglas o partes de palabras que se leen como una palabra |
| **Compliance** | Procedimientos que garantizan el cumplimiento de normativa interna, ley y códigos éticos |
| **DataMining** | Técnicas para buscar patrones no evidentes en grandes BD |
| **DataWarehouse** | Almacén de datos que incluye **metadatos** (procedencia, refresco, fiabilidad...) |
| **Workflow** | Automatización regulada de procesos para que tareas e información circulen en orden |
| **KPI** | Indicador clave de desempeño |
| **OLAP** | BD multidimensionales orientadas al análisis |
| **ROI** | Retorno de la inversión: tiempo para recuperar lo invertido |
| **Sistema de información** | Datos convertidos en información mediante procesos automatizados |
| **Sostenibilidad** | Equilibrio entre crecimiento económico y medio ambiente |
| **TIC** | Hardware y software para almacenar, tratar y transmitir información |
| **Transacción** | Todo lo que modifica o genera datos de un sistema de información |
