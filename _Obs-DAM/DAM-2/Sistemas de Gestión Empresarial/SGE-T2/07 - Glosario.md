# 07 · Glosario

Anterior: [[06 - Inteligencia de negocio (BI)]] · Siguiente: [[08 - Actividades y supuestos prácticos]]

| Término | Definición |
|---|---|
| **B2B** (*Business to Business*) | Transacciones comerciales entre **empresas**. |
| **B2C** (*Business to Customer*) | Transacciones entre empresas y **consumidores finales**. |
| **Back-Office** | Actividades **administrativas** de procesos internos. Mantienen a la empresa en funcionamiento. |
| **Front-Office** | Actividades **de cara al cliente**. Son las que generan los beneficios. |
| **Big Data** | Procesamiento de volúmenes muy grandes de datos de todo tipo. |
| **Cloud Computing** | Computación en la nube: servicios (hardware y software) a través de internet. |
| **e-commerce** | Comercio electrónico: compra y venta a través de internet. |
| **IoT** (*Internet of Things*) | Conexión de todo tipo de dispositivos electrónicos a través de internet. |
| **Know-how** | "Saber hacer". Conocimientos **no protegidos** que dan ventaja competitiva. |
| **On-Premise** | Instalación **en local**: los servicios están en la propia empresa. |
| **SaaS** (*Software as a Service*) | Software como servicio: el proveedor ofrece licencias de uso a través de internet. |
| **ETL** (*Extract, Transform and Load*) | Extracción, transformación y carga posterior. |
